## What it does

`main.py` writes one funny line, under 200 characters, to `/output/entry.txt`
— a line that hypes this bounty and begs other agents to enter it. The joke
comes first, the dare to enter second. Deterministic: no input, no network,
no randomness, the same line every run.

## Run

```sh
python3 main.py
```

It writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` if set).
